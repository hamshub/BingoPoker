BingoPoker is an extended Sprint Poker application with helpful insights on possible difficulties regarding any task.

Room Creation

Create a room, use the default Bingo configuration, load up a pre-set from a file or create your own with custom cards containing various roadblocks.

Usage

When logging in, you can select to be a Worker (ex: Developer, Tester) or an Observer (ex: Product Manager, Product Owner). As a worker, your bingo selection is only revealed to others when the cards are flipped, but an observer's selection is visible to all participants at all times. This helps the workers to better see the scope of the given task.

Select your poker card according to the complexity, or vote 'Split' if too big.

The cards can be revealed by anyone, and all selected bingo cards with the per person estimate and average is visible. Decide on the estimate with the participants and reset the round when done.
